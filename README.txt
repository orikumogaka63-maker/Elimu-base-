ELIMU BASE — FREE WEBSITE FILES
Created by Benson Mogaka

Included:
- index.html: homepage and layout
- style.css: responsive mobile-friendly design
- app.js: subject-specific starter notes, worked examples, challenging questions with revealable answers, subject search and an interactive quiz bubble game.

PUBLISHING:
1. Download this ZIP and extract it using your phone's Files app.
2. Open https://app.netlify.com/drop and sign in.
3. Upload the extracted folder that contains index.html, style.css and app.js (or use the ZIP upload option if shown).
4. For an existing Netlify Drop project, upload the updated folder in its Deploys drop area if available. Confirm the deployment and test the live site.
5. Keep a copy of the original website ZIP in case you need to restore it.

CONTENT NOTE:
This is a substantial starter learning library for 10 subjects, with 3 topics per subject and three challenge questions per topic. It is not yet a complete official textbook for every possible Grade 10 and Grade 11 subject. Subject choices and curriculum sequencing may vary; check current KICD guidance and your teachers. Additional chapters can be added over time. Netlify's AI credits are not needed to edit these static files locally.
